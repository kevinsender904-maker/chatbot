# API Documentation

## Chat Endpoint

**POST** `/api/chat`

Handles conversational input, injects medical intelligence context, and returns a streamed Server-Sent Events (SSE) response from the Gemini API.

### Request Format

```json
{
  "messages": [
    {
      "role": "user",
      "content": "I have a headache and a mild fever."
    }
  ]
}
```

- **messages**: Array of message objects representing the conversation history. The last message must have `role: "user"`.

### Response Format (Server-Sent Events)

The response uses `text/event-stream` for real-time text delivery.
Each chunk contains the text segment generated by the LLM.

```text
data: {"text": "Based on your symptoms,"}

data: {"text": " it could be..."}

data: [DONE]
```

### Error Responses

If the Gemini API key is missing or invalid:
```json
{ "error": "Gemini API key is not configured." }
```

In the event stream:
```text
data: {"error": "An error occurred fetching response"}
```
